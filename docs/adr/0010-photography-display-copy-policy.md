# 摄影展示副本：画质优先，原图不入云

摄影作品的展示副本采用视觉无损策略：大图 WebP 质量 95、长边 3000px，缩略图 WebP 质量 85、长边 800px，均剥离 EXIF；原图（含 RAW）只保存在站主本地，作为唯一真源。拍摄时间、地点（GPS）与拍摄参数在上传加工时提取到 SQLite，仅以文字展示。

Status: proposed

## Considered Options

- **原样 JPEG 直传**：零重编码，但体积大一个量级，且 EXIF（含 GPS）会随文件公开。
- **云端厂商图片处理**：省流量但绑定厂商私有能力，与 Provider 解耦目标冲突。
- **AVIF 变体**：压缩率更高，但编码兼容成本高；后续可作为增量变体加入。

## Consequences

- 3000px 长边覆盖 4K 显示上限，网页上无可见画质损失，单张体积可控。
- 云端文件不携带拍摄者隐私（位置、相机序列号等），参数仍可在详情页展示。
- 厂商数据丢失时，从本地原图重新上传即可恢复。
