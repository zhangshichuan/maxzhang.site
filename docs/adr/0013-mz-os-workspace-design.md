# ADR-0013: MZ/OS 工作台视觉与静态内容体系

Status: accepted

Date: 2026-10-18

## Context

站点此前已经过一次深色 AI Native 改版和一次文案重构，但页面语法仍是「顶部导航 + 居中 Hero + 卡片/分栏」，与任何作品集模板没有本质区别。用户明确要求「脱离常规」，并选择设计探索中的方向 C：把网站做成一个 AI 产品工作台；同时要求静态内容体系完全重写，以「乔布斯会怎么做」为判断标准——聚焦、删减、演示而非陈述。

## Decision

1. **视觉方向切换为 MZ/OS 工作台**：石墨黑底 + 荧光绿状态色 + mono 系统标签 + 1px 面板 + 无圆角装饰；系统栏承载品牌、路径与导航；页面由面板组成，而不是营销区块。
2. **页面结构重写**：导航从 5 项减到 3 项（概览 / 写作 / 关于），摄影、树洞、搜索收进「更多」；首页收敛为 Hero + KPI + 案例 + 三条判断 + 方法 + 写作 + 终端 + 联系；关于页改为自述 + INFO + 经历 + 联系。
3. **新增「终端」彩蛋**：首页可输入 `help`、`work`、`notes`、`about`、`contact`、`clear`，作为「one more thing」，不引入新依赖。
4. **静态内容体系整体重写**（zh/en）：第一人称、短句、证据优先；删除课程/学习/转型叙事、技能云和多余 CTA；写作以系列计划呈现（AI 产品方法 / 案例拆解 / 工程实践）。
5. **样式落地**：`design-system.css` 更新 token 与基础壳层；新增 `styles/os.css` 承载新页面语法；旧 `content/pages` 样式保留，由 token 继承新皮肤。所有页面保持静态渲染与现有路由。

## Consequences

- 首页与关于页的组件、`messages/{zh,en}.json` 中对应命名空间完全替换；旧 `Theses` 等命名空间移除。
- 摄影、树洞、搜索、后台只做 token 级换肤，控件逻辑不变；后续需要时再逐个重写。
- 视觉记忆点从「渐变 + 卡片」转为「界面 + 面板 + 路径 + 终端」，与「AI 产品经理 + 十年工程」的定位一致。
- 字号与信息密度提高，移动端依赖压缩后的 KPI/面板布局；后续新增内容必须遵守「每增加一个区块，就删掉一个旧区块」的编辑规则。
- 课程内容不再进入静态页面，后续以系列文章形式在 `/posts` 产出。
