# 以 iOS 27 液态玻璃设计系统取代 Glitch Core

Status: accepted

原站点使用 “Glitch Core” 视觉语言（纯深色、赛博朋克、粒子场、扫描线与毛刺动效），仅支持深色外观。重设计决定整体替换为 Apple iOS 27 的 Liquid Glass 设计系统：深/浅色自适应、系统蓝强调色、系统字体栈、弹簧动效、可调玻璃强度（Clear ↔ Tinted）与缓慢流动的抽象渐变壁纸；信息架构、内容与功能保持不变，只重做视觉与交互层。

## Considered Options

- **保留 Glitch Core 并叠加玻璃质感**：可保留个人识别度，但无法达到“完全 iOS 27 原生感”，且旧动效与克制的新材质体系冲突。
- **混合路线（玻璃材质 + 霓虹签名色）**：识别度更高，但偏离用户明确选择的“完全 iOS 27”，需维护两套色彩语义。
- **完整系统还原（已选）**：材质、配色、字体、动效全部对齐 iOS 27，用户明确确认。

## Consequences

- 全站需要一套新的设计令牌（深浅色语义色、玻璃强度、圆角、间距），旧的 Glitch 专属类名与 CSS 全部移除。
- 需要双形态导航（桌面顶部玻璃工具栏 + 移动端底部玻璃标签栏），比单一导航多一份实现与测试。
- 代码块需要构建期语法高亮（跟随深浅色，Shiki 4 默认包不含 Xcode 主题，采用同风格 VS Code Light+/Dark+ 双主题），MDX 编译管线已引入 rehype-pretty-code。
- 背景模糊与渐变动画对低端移动设备有性能成本，玻璃仅用于镶边与卡片，正文保持系统实底。
- `prefers-reduced-motion` 下所有持续动画降级为静态。
