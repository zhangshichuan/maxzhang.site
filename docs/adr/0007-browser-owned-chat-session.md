# 会话由浏览器持有，聊天服务保持无状态

Status: accepted

算命是多轮对话，但聊天服务不保存任何会话状态：前端每次请求携带完整消息数组，服务端把数组原样拼进 DeepSeek 请求后即忘。会话历史由浏览器按日期存入 localStorage（仅保留最近 3 天），刷新不丢、次日自动开新会话。这样服务无状态、可水平扩展、重启无副作用；代价是无法跨设备续聊，且限额逻辑必须留在 web 层（按浏览器指纹统计，每个指纹每日 100 轮、每小时 50 条）。

Considered Options:

- 服务端按指纹存会话：前端零改动，但有状态、重启丢记忆、需要过期清理。
- 单轮无记忆：服务最简单，但算命无法连续对话。
