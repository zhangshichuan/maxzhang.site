# 聊天页从算命师转向树洞

聊天页原本是《鬼吹灯》风格的算命先生人设（半文半白、随机口头禅、绝不承认 AI），用户要求全面替换为“树洞”：一个无身份背景的倾听者，内化阿德勒心理学、《被讨厌的勇气》《自卑与超越》、王阳明心学、中国佛学、《毛泽东选集》前三卷与《月亮与六便士》来共情与鼓励；导航与文案同步从“算一卦/Fortune”改为“树洞/Tree Hole”，“故事会/Journal”改为“文章/Articles”，页面视觉保持 Liquid Glass 设计不变。

选择树洞是因为原人设表演感过重，且带有《鬼吹灯》角色版权与系统性否认 AI 身份的风险；树洞没有人物卡、被问及时诚实承认 AI 身份、行为规则更可维护。代价是失去“玄学娱乐”的差异化趣味，聊天页从算命消遣变为情绪陪伴，且需要额外的安全边界（危机信号温柔转介、不冒充专业人士）。

Status: accepted

Considered Options:

- 保留算命师只调文风：改动最小，但人设骨架（身份否认、江湖戏腔）与用户不满的根源仍在。
- 新增树洞入口、算命师并存：一个页面两种人设维护成本翻倍，定位精神分裂。
