Go 是一门很适合工程落地的语言。

它的语法不花哨，编译快，部署简单，并且天然适合写服务端、命令行工具、云原生组件和高并发程序。很多人第一次接触 Go，会觉得它“语法不多但规矩很多”。这恰恰是它的价值所在: 团队协作成本低，代码风格统一，项目维护起来更稳定。

这篇文章按“能尽快上手实际开发”的思路来写，不追求面面俱到，但会覆盖现代 Go 开发最常用的部分。

## 1. Go 是什么，适合做什么

Go 由 Google 在 2009 年开源，设计者包括 Robert Griesemer、Rob Pike 和 Ken Thompson。它的核心目标很明确:

- 语法简单，降低工程复杂度
- 编译速度快，适合大项目持续迭代
- 标准库强，减少不必要依赖
- 并发模型直接，适合服务端场景

Go 常见应用场景包括:

- Web API 与微服务
- 云原生基础设施
- CLI 工具
- 中间件、代理、任务调度系统
- 分布式系统与高并发服务

如果你来自 JavaScript、Python 或 Java 背景，Go 最明显的体验通常是:

- 写法比 Java 简洁
- 部署比 Python 直接
- 并发比传统线程模型更轻量
- 约束比动态语言更多，但长期维护更省心

## 2. 开发环境与第一个程序

### 2.1 安装 Go

常见安装方式:

```bash
# macOS
brew install go

# Windows
winget install GoLang.Go

# Ubuntu / Debian
sudo apt update
sudo apt install golang-go
```

安装后检查版本:

```bash
go version
```

### 2.2 推荐开发工具

- VS Code + Go 插件: 轻量、社区资料多
- GoLand: 调试和重构体验更完整
- Neovim / Vim: 适合终端重度用户

### 2.3 第一个 Go 程序

创建 `main.go`:

```go
package main

import "fmt"

func main() {
    fmt.Println("Hello, Go!")
}
```

运行:

```bash
go run main.go
```

## 3. 先理解 Go 项目的基本形状

现代 Go 开发里，`go mod` 是必须掌握的。

### 3.1 初始化模块

```bash
mkdir hello-go
cd hello-go
go mod init github.com/yourname/hello-go
```

执行后会生成 `go.mod`，它记录当前项目的模块名和依赖信息。

一个最小项目通常长这样:

```text
hello-go/
├── go.mod
├── go.sum
├── main.go
└── internal/
    └── service/
        └── user.go
```

### 3.2 常见 Go 命令

```bash
go run .
go build .
go test ./...
go fmt ./...
go mod tidy
go doc fmt.Println
```

它们分别用于:

- `go run .`: 直接运行当前模块
- `go build .`: 编译当前项目
- `go test ./...`: 递归运行全部测试
- `go fmt ./...`: 统一格式化代码
- `go mod tidy`: 清理和补全依赖
- `go doc`: 查看包、函数和类型文档

## 4. 基础语法速览

### 4.1 变量与基本类型

```go
package main

import "fmt"

func main() {
    var name string = "Go"
    var age = 16
    city := "Shanghai"

    var enabled bool = true
    var score float64 = 99.5

    fmt.Println(name, age, city, enabled, score)
}
```

Go 常见基本类型:

- `bool`
- `string`
- `int` / `int64`
- `float32` / `float64`
- `byte`
- `rune`

### 4.2 `if`、`for`、`switch`

```go
score := 85

if score >= 90 {
    fmt.Println("优秀")
} else if score >= 60 {
    fmt.Println("及格")
} else {
    fmt.Println("不及格")
}

for i := 0; i < 3; i++ {
    fmt.Println(i)
}

day := 3
switch day {
case 1:
    fmt.Println("Monday")
case 2:
    fmt.Println("Tuesday")
case 3:
    fmt.Println("Wednesday")
default:
    fmt.Println("Unknown")
}
```

Go 只有 `for`，没有 `while`。但 `for condition {}` 就能完成同样的事。

### 4.3 函数、多返回值、错误值

```go
package main

import (
    "errors"
    "fmt"
)

func divide(a, b int) (int, error) {
    if b == 0 {
        return 0, errors.New("divisor cannot be zero")
    }
    return a / b, nil
}

func main() {
    result, err := divide(10, 2)
    if err != nil {
        fmt.Println("error:", err)
        return
    }

    fmt.Println("result:", result)
}
```

Go 很强调显式错误处理。没有异常链式传播的“魔法感”，但可读性和控制感更强。

### 4.4 数组、切片、Map

```go
package main

import "fmt"

func main() {
    arr := [3]int{1, 2, 3}
    nums := []int{10, 20, 30}
    nums = append(nums, 40)

    profile := map[string]string{
        "name": "Max",
        "role": "developer",
    }

    fmt.Println(arr)
    fmt.Println(nums)
    fmt.Println(profile["name"])
}
```

实际业务里:

- 数组用得不多，因为长度固定
- 切片非常常见，是 Go 里最重要的数据结构之一
- `map` 常用于字典、索引、计数和缓存

## 5. 结构体、方法与接口

### 5.1 结构体与方法

```go
package main

import "fmt"

type User struct {
    Name  string
    Email string
}

func (u User) DisplayName() string {
    return u.Name + " <" + u.Email + ">"
}

func (u *User) UpdateEmail(email string) {
    u.Email = email
}

func main() {
    user := User{Name: "Max", Email: "old@example.com"}
    user.UpdateEmail("new@example.com")
    fmt.Println(user.DisplayName())
}
```

一般规则:

- 不修改接收者状态时可用值接收者
- 需要修改字段或避免大对象拷贝时用指针接收者

### 5.2 接口

```go
package main

import "fmt"

type Speaker interface {
    Speak() string
}

type Dog struct{}

func (Dog) Speak() string {
    return "wang"
}

func printSpeech(s Speaker) {
    fmt.Println(s.Speak())
}

func main() {
    d := Dog{}
    printSpeech(d)
}
```

Go 接口的关键特点是“隐式实现”。一个类型只要方法集合匹配，就自动满足该接口，不需要显式声明。

这让代码解耦很自然，尤其适合:

- 依赖抽象而不是具体实现
- 单元测试中替换依赖
- 包级边界隔离

## 6. 并发编程: goroutine 和 channel

Go 的并发是它最有辨识度的特性之一。

### 6.1 goroutine

goroutine 可以理解为非常轻量的并发执行单元。

```go
package main

import (
    "fmt"
    "sync"
)

func worker(name string, wg *sync.WaitGroup) {
    defer wg.Done()
    fmt.Println(name, "working")
}

func main() {
    var wg sync.WaitGroup

    wg.Add(2)
    go worker("job-1", &wg)
    go worker("job-2", &wg)

    wg.Wait()
}
```

这里使用 `sync.WaitGroup` 来等待任务完成。比用 `time.Sleep` 或 `select {}` 更适合教程和真实项目。

### 6.2 channel

channel 用于 goroutine 之间通信。

```go
package main

import "fmt"

func producer(ch chan<- int) {
    for i := 1; i <= 3; i++ {
        ch <- i
    }
    close(ch)
}

func main() {
    ch := make(chan int)

    go producer(ch)

    for n := range ch {
        fmt.Println("received:", n)
    }
}
```

一个很常见的 Go 思路是:

- 不急着共享内存
- 优先考虑通过通信传递数据

当然，真实项目里也会大量使用 `sync.Mutex`、`context.Context`、`errgroup` 等工具。

## 7. Web 开发最小示例

Go 标准库自带 `net/http`，写一个最小 HTTP 服务非常直接。

```go
package main

import (
    "encoding/json"
    "log"
    "net/http"
    "time"
)

type Response struct {
    Message string `json:"message"`
    Time    string `json:"time"`
}

func helloHandler(w http.ResponseWriter, r *http.Request) {
    w.Header().Set("Content-Type", "application/json")

    resp := Response{
        Message: "Hello, Go Web!",
        Time:    time.Now().Format(time.RFC3339),
    }

    if err := json.NewEncoder(w).Encode(resp); err != nil {
        http.Error(w, err.Error(), http.StatusInternalServerError)
    }
}

func main() {
    http.HandleFunc("/hello", helloHandler)

    log.Println("server listening on :8080")
    log.Fatal(http.ListenAndServe(":8080", nil))
}
```

启动后访问 `http://localhost:8080/hello` 即可看到 JSON 响应。

## 8. 测试、格式化与工程习惯

### 8.1 单元测试

创建 `math_test.go`:

```go
package main

import "testing"

func Add(a, b int) int {
    return a + b
}

func TestAdd(t *testing.T) {
    got := Add(2, 3)
    want := 5

    if got != want {
        t.Fatalf("got %d, want %d", got, want)
    }
}
```

运行测试:

```bash
go test ./...
```

### 8.2 推荐养成的习惯

- 提交前运行 `go fmt ./...`
- 依赖变动后执行 `go mod tidy`
- 不忽略错误值
- 优先写小函数和清晰包边界
- 在公共 API 中尽量保持命名稳定

## 9. 新手最容易踩的坑

### 9.1 以为 `slice` 是值拷贝语义

切片本身会拷贝一份描述符，但底层数组可能仍然共享，因此修改元素时要清楚影响范围。

### 9.2 滥用 goroutine

goroutine 很轻量，但不是免费。无上限地开 goroutine，最后往往会把系统压垮。要配合并发控制、超时和取消机制使用。

### 9.3 忽略 `context`

一旦项目涉及 HTTP、数据库、RPC、任务链路，`context.Context` 基本是标配。它负责传递超时、取消信号和请求级元数据。

### 9.4 用面向对象思维硬套 Go

Go 有方法和接口，但它不是传统意义上那种重继承、重层级的 OOP 语言。更适合小接口、组合优先、数据结构清晰的写法。

## 10. 一条实用学习路线

如果你想在两周内把 Go 跑通到“能写项目”的程度，可以按这个顺序学:

1. 语法基础、函数、多返回值、错误处理
2. 切片、Map、结构体、方法、接口
3. `go mod`、包管理、项目结构
4. goroutine、channel、`sync`
5. `net/http`、JSON、配置、日志
6. 测试、数据库、部署

一开始不必把所有高级特性都学完。先把“小而完整”的服务写出来，再逐步补性能、并发和架构设计，会更有效。
