# Max Zhang 个人网站

Max Zhang 的个人技术品牌网站，展示技能矩阵、技术文章和 AI Agent 工程实践。

## 语言

**Language**：核心编程语言，只列实际在生产中使用过的。
_Avoid_: 学过但未用于实际项目的语言

**Skill Matrix**：首页四象限技能展示，按 Languages / Frameworks / Infrastructure / Data Layer 分类。每项必须满足"真用过"原则。

**Article**：技术长文，以 MDX 组织，双语（zh/en）。按标签和分类检索。
_Avoid_: 博客（blog）、帖子（post）— 统一用「文章」

**Agent**：
AI Agent 系统，具备感知、决策、执行能力。涵盖 MCP（工具调用协议）、A2A（Agent 间通信）、ReAct（推理-行动循环）。
_Avoid_: 机器人、bot、自动化脚本

**Infrastructure**：
应用运行时和通信层，包括容器编排（Docker/K8s）、云平台（AWS/Vercel）、Agent 协议（MCP/A2A）、沙箱执行环境（Playwright）、CI/CD。
